Bem-vindo ao nosso analisador de código JavaScript!

O objetivo deste projeto é analisar código estaticamente, identificando violações de boas práticas que podem prejudicar a qualidade do software.

Destaques

O projeto faz uma análise inicial de código JavaScript. Futuramente iremos expandir para outras linguagens.

Funcionalidades

  • Análise de Parâmetros
  • Análise de Nomes de Função
  • Complexidade Ciclomática
  • Verificação de Comentários
